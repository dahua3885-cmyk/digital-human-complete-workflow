# 中英文发音核验

## 何时强制触发

口播稿中出现英文单词、英文人名、品牌/产品名、缩写、模型名或可能存在中国用户惯用读法的词时，生成正式音频前必须联网核验“中国人实际怎么念”。不得只凭英文词典、模型默认读法或搜索摘要猜测。

## 证据优先级

1. 品牌、产品或机构的中文官网、官方中文活动、官方中文视频/直播中的可听读法。
2. 可靠的中文科技、行业或新闻媒体中，能实际听到主持人或专业人士读出的材料。
3. 多名高质量中文从业者在真实讲解中的一致读法。

搜索结果文字、网页标题或拼音转写只能帮助定位，不能单独证明发音。至少取得 1 个可听中文语境来源；重要品牌或存在争议时尽量取得 2 个独立来源。

## 操作步骤

1. 从显示稿提取全部候选词，保留原始大小写、上下文和出现次数。
2. 核对官方英文拼写、官方中文名及是否存在品牌指定读法。
3. 联网寻找可听的中文语境，记录页面标题、URL、发布日期/访问日期、说话人或场景、实际听到的读法。
4. 将候选读法放回原句，生成 2–3 个完整语义句试听；禁止只生成孤立单词。
5. 来源一致且听感清楚时写入 `pronunciation-research.md`；来源冲突、听不清或找不到可听来源时，列出候选并让用户明确选择，不自行定案。
6. 用户确认后，把书写形式、口语形式、适用上下文、来源 URL、置信度和批准样本哈希写入 `voice-profile.json` 的 `pronunciation_lexicon`。

## 记录格式

```text
书写形式：
所在原句：
官方中文名：
来源 1：标题 / URL / 日期 / 中文语境 / 听到的读法
来源 2：标题 / URL / 日期 / 中文语境 / 听到的读法
候选试听：
用户确认读法：
适用范围：当前句 / 当前项目 / 该人物长期词典
置信度：高 / 中 / 低
批准样本 SHA-256：
```

## 适用范围与边界

- 同一缩写在不同领域可能读法不同，必须绑定上下文。
- 品牌官方读法更新、用户明确改口、语言或声音模型变化时重新验证。
- 发音词典是模型适配层，不得改动屏幕显示稿的正确拼写。
- 只有授权来源可下载或归档；不能归档时只保存页面信息、访问日期和听辨结论。

支持发音词典的引擎可以把确认结果写入引擎词典；例如 ElevenLabs 提供发音词典机制，但具体格式和模型支持范围需按其当前官方文档核对：<https://elevenlabs.io/docs/eleven-api/guides/how-to/text-to-speech/pronunciation-dictionaries>。
