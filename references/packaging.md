# 剪辑包装

本工作流只提供这一种剪辑包装，不询问版式，不显示历史版本编号或内部母版名称。用户没有明确要求另做定制工程时，始终使用本文件。

## 固定区域

```text
画布：1080×1920，30fps
主信息区：left 60 / top 80 / width 960 / height 1055
字幕框：left 60 / top 1165 / width 960 / height 88
人物窗口：left 580 / top 1285 / width 450 / height 445
人物裁切初始值：object-fit cover; object-position 50% 43%
人物圆角：48px
人物色调：brightness(.92) contrast(1.05) saturate(.9)
```

- 人物固定在右下角；不同源片只校准人物窗口内部裁切。
- 主信息区底边 `y=1135`，距字幕顶边 30px；内容应利用完整信息区。
- 人物窗口不加描边、发光、投影、角标和底板。

## 视觉系统

- 背景以黑色/深海军蓝为主：`#020711`，叠加低透明度青蓝径向光和 56px 网格。
- 主强调：`#22c5ff`；主文字：`#f4f8ff`；次级文字：`#91a6bb`；面板：`#07121f`。
- 中文字体：Noto Sans SC。一级标题约 `82px/920`；眉题 `29px/820`；卡片主文案基准 `32px/880`；核心解释不得小于 28px。
- 字幕：Noto Sans SC，48px/500，`#f4f4f1`，单行、无标点、无底板。
- 真实外加视频可使用橙色识别边框 `#ff9f43`；静态证明图可使用紫色边框 `#8b5cf6`；人物窗口始终无边框。
- 软件自身品牌色只用于 Logo 和局部身份，不改变整片青蓝主色。

不得出现任何特定创作者姓名、签名、头像、Logo 组合或封面母图作为公共默认。人物图、品牌名和署名从当前本地 Profile 与授权素材读取。

## 内容与时间轴

制作前必须存在：

- `content-hierarchy.md`：全片主题 → 段落主旨 → 句级重点 → 例子/证据。
- `timeline.md`：原声起止、触发词、元素、入退场和视觉作用。
- `asset-map.md`：素材、来源、授权、用途、时间、是否 AI 生成。

所有标题、Logo、界面、图片、流程、框选和状态跟随真实口播触发；不得按固定间隔或 DOM 顺序播放。包装文字不复述字幕；解释画面除明确结论外至少包含一种非文字信息载体。

## 素材证据

优先级：用户真实素材 → 官方 Logo/界面/录屏 → 可核公开证据 → 语义图形 → 明确标注的 AI 说明图。

- 软件首次成为主体时展示官方 Logo。
- 讲功能、步骤或结果时优先展示真实界面或真实录屏。
- 不用 AI 生成图伪造官方界面、真人、数据、证书、新闻、客户案例和实际成果。
- 用户指定完整素材时用 `contain` 或重设容器保留四边，不强裁为方框。

## 动效与样片

- 普通入场使用轻微 `opacity / x / y / scale`，约 0.18–0.42 秒，使用 `power2.out / power3.out / expo.out`。
- 禁止整页统一淡入、PPT 翻页、Logo 弹跳/回弹、持续缩放和无意义漂移。
- 全片前先做 5–12 秒代表性内部样片，覆盖人物裁切、字幕、真实触发和非纯文字画面；软件内容还覆盖官方 Logo 与真实界面。

## 统一封面

- 必交 9:16、3:4、1:1 三种独立构图，不用同一张图机械裁切。
- 延续黑色/深海军蓝背景、青蓝强调光、信息网格和高对比中文标题；标题简短清楚，不让 AI 图片模型生成文字。
- 使用当前人物已授权的真实清晰肖像；只有授权明确包含肖像衍生生成时，才可用 AI 辅助人物封面。不得出现身份漂移、多余肢体、错误服装或虚构场景事实。
- 涉及产品或软件时使用核验过的官方 Logo；不伪造界面、证书、媒体报道或结果。
- 发布版视频开头放约 0.1 秒封面。合成后检查音轨和第一句完整，封面不得盖住第一个字。

## 固定交付

- 无封面母版 MP4。
- 带约 0.1 秒封面的发布版 MP4。
- 9:16、3:4、1:1 三张独立封面 PNG。
- 工程、样片、关键帧、素材来源、`revision-log.md`、`qa-report.md` 和 `delivery-manifest.json`。

最终文件必须检查 1080×1920、30fps、H.264、AAC、时长、首尾帧、字幕、触发同步、人物裁切、封面身份一致性和连续播放。
