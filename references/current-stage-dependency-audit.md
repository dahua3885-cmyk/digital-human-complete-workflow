# 现有四个专用阶段 Skill｜公开发行依赖审计

审计日期：2026-08-27。只读核对，未修改原 Skill。

## 结论

四个现有 Skill 都是面向当前作者和机器环境的专用实现，不能原样作为“所有用户下载即运行”的公共依赖。公共版必须新增通用阶段 Skill/适配器，或把可复现的安装源、模型/服务配置和路径参数化后单独发布；不能把真人素材和作者机器路径复制进公开仓库。

## 二创

- Skill 本体和交付验证脚本存在。
- 实际链接采集、登录、下载和转写依赖作者工作区中的抖音采集工具，未包含在该 Skill 目录。
- 默认输出和项目上下文指向作者本机D盘工作区。
- 内容风格和身份明确绑定“大华”，不能作为律师、教师或其他创作者的通用实现。

## 数字人音频

- 依赖 F5-TTS、Faster-Whisper、特定 Python 环境、模型权重、Vocos和本地参考声。
- Skill 目录包含大华音频基线资产；参考声和权重路径指向作者本机测试工作区。
- 速度、seed、参考声、英文历史和验收都绑定大华本人。
- 这些私人音频、路径和人物参数不得进入公共通版。

## 数字人画面

- 依赖 Python、CUDA、FFmpeg/FFprobe、MuseTalk v1.5仓库和权重、Faster-Whisper及授权真人模板。
- 多个脚本默认路径指向作者本机测试工作区；模板循环区间和显存经验绑定当前真人素材及RTX 4050 6GB环境。
- 缺模型仓库、权重、参考模板和运行环境时不能生成画面。

## 剪辑包装

- 依赖 FFprobe、HyperFrames及作者机器上的隐藏窗口补丁/调用脚本。
- 归档、素材真源和批准母版包含作者本机D盘及用户目录路径。
- 原Skill仍提供三个历史版本，而公共总控要求只使用固定竖屏右下人物布局。
- 含作者封面参考资产和专用品牌规则，不能直接作为公共默认。

## 对发行包的决定

- 不复制、重命名或修改上述四个专用 Skill。
- 0.8发行包增加四类反馈沉淀、资产中心、任务串联与验证层，并继续明确标记 `end_to_end_runtime_included=false`；不包含可视化工作台。
- 正式1.0之前需要四个通用阶段实现、固定版本安装源和端到端演示；否则完整性校验可以通过，但运行预检必须失败。
