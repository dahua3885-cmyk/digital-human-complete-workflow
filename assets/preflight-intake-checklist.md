# 数字人完整流程｜首次启用与每条项目资料清单

> 第一次启用时一次说明完整需求，避免做到一半才告诉用户还要录声音或人物样片。长期资料本地建档并复用；每条项目只补变化。资料按阶段提交，不要求一次上传全部敏感文件。

本清单不是第二份创作者资料问卷。用户已经完整回传简洁版或专业版后，必须直接完成创作者建档；下列使用目的、入口材料、授权和交付目标只在用户实际发起某条制作任务时按需收集，不能在建档后一次性追问。动态事实默认由 AI 核验公开来源，资料默认仅在本机长期复用，不再询问用户“是否预确认”和“保存范围”。

## 安装完成后先做什么

1. 选择本地工作区和准备启用的模块：二创 / 数字人音频 / 数字人形象 / 剪辑包装。
2. 首次只选择基础信息简洁版或专业版；数字人全流程与分别制作始终同时可用，声音、形象和包装资料进入对应模块时再补。
3. 完成合法使用声明和本人/第三方关系说明。
4. 选择简洁版或专业版创作者资料。
5. 需要数字人音频时，按 [首次声音建档](../references/audio-onboarding.md) 录参考声并三风格盲听。
6. 需要数字人形象时，先读录制清单，再录参考视频。
7. 建立品牌包装资料；暂时没有的素材可保持待补。

安装不会自动上传或收集真人资料。第一次调用时由用户选择工作区后建档。

## 第一步：选择入口和终点

- [ ] 完整流程：视频链接/本地视频/逐字稿 → 二创 → 音频 → 数字人画面 → 剪辑包装
- [ ] 文案入口：已有最终文案 → 音频 → 数字人画面 → 剪辑包装
- [ ] 音频入口：已有确认音频 → 数字人画面 → 剪辑包装
- [ ] 包装入口：已有数字人/真人口播视频 → 剪辑包装
- [ ] 本次只做到：文案 / 音频 / 数字人画面 / 最终包装

执行者先把下列项目标成“长期已建档 / 现在提交 / 后续提交 / 不适用”，再开始收集。

## 实际发起一条制作任务时需要

1. **使用目的**：内容主题、目标平台、发布地区、是否商业使用、最终由谁发布。
2. **人物关系**：数字人是本人，还是已取得授权的第三方；第三方需说明关系和授权证据类型。
3. **合法使用声明**：完成 [合法使用与授权声明](lawful-use-and-consent-declaration.template.md)。
4. **入口材料**：视频链接、本地媒体、逐字稿、最终文案、确认音频或待包装视频中的一种。
5. **交付目标**：需要哪些阶段、预计时长、语言、截止时间和品牌要求。

## 二创需要

- 创作者资料二选一：
  - [简洁版](creator-profile-quick.template.md)：约 5–10 分钟，适合快速开始，结果更偏通用。
  - [专业版](creator-profile-pro.template.md)：适合长期稳定生产，文案更贴合职业、案例和表达习惯。
- 简洁版逐项完成即满足通用二创的最低创作者资料要求；样本、真实案例或免责声明明确写“无 / 暂无”时不得阻塞或追加整套问题，改用保守、不虚构的表达。
- 专业版可提供更多本人文案、真实案例、事实来源和表达指纹，但不得把这些专业版字段强加给已经选择简洁版的用户。
- 高风险职业需提供真实资质边界、适用地域/法域和免责声明规则。

## 数字人音频后续需要

- 首次建档时录制通用声音母素材，建议 2–5 分钟干净人声；具体模型实际使用的片段长度和格式按绑定声音 Skill。
- 声音授权证据；第三方声音必须单独授权，不能只用肖像授权代替。
- 专有词、英文品牌名和希望的读法；未确认读法将先联网核验中文真实语境。
- 参考声先做单人、噪声、混响、削波、ASR和身份体检；严重不合格时重录。
- 第一次会收到同文案 A/B/C 盲听三种试听，选择后才揭示风格名称，并用另一段文案验证；同一声音组合以后沿用。
- 每条新视频仍要检查新增英文/数字风险句、完整音频 ASR/响度/吞字/重复，并由用户试听确认。

## 数字人画面后续需要

- 获授权的真人参考视频。正式推荐 60–90 秒、一镜到底、单人、固定机位、脸嘴无遮挡、静态背景；录制前先阅读 [样片录制清单](avatar-recording-checklist.md)。
- 肖像和嘴部驱动授权证据；第三方需提供能绑定本项目、用途、平台和期限的证据。
- 人物称呼、是否本人、发布平台、商业使用、授权期限和撤回方式。

## 剪辑包装后续需要

- 已确认的最终人物视频、文案/字幕和音频交接链。
- 品牌名、官方 Logo、真实界面/录屏、指定图片视频及其授权来源。
- 封面人物授权图和标题方向。默认固定竖屏、人物右下、黑色背景、青蓝强调。
