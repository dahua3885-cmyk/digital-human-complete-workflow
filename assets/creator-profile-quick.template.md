# 创作者资料｜简洁版

> 适合快速开始，预计填写 8–12 分钟。逐项作答后即可建立个人资料；可选项没有内容时填写“无”或“暂无”，不需要再填写第二套资料。

```text
资料版本：基础信息简洁版
【我的基本信息】
账号称呼：
职业 / 身份：
行业或内容领域：

【我的受众与内容】
核心受众：
受众最常见的3个问题：
长期想讲的3–5个内容方向：
希望带来的价值或账号目标：

【我的表达与边界】
表达风格：
可公开的真实经历、资源或案例：
不希望出现的表达或内容：
本人文案、逐字稿或视频链接：
资质边界、地区限制或免责声明：
```

## 填写提示

- 核心受众：写“谁、现在处于什么状态、想解决什么问题”。
- 受众问题：写他们经常问、经常卡住或最担心的三件事。
- 内容方向：写以后经常发布的3–5个固定栏目。
- 价值或目标：写希望帮助观众获得什么，以及希望账号实现什么。
- 真实材料：只写真实发生且允许公开的内容，没有可写“暂无”。
- 专业边界：需要免责声明时填写，没有可写“无”。
