# 创作者资料｜专业版

> 适合希望二创长期稳定贴合本人、行业与账号定位的用户。专业版已经包含简洁版所需内容，不需要同时填写简洁版。

```text
资料版本：基础信息专业版
【基本定位】
账号称呼：
职业 / 身份及从业方向：
行业或内容领域：
核心受众及其所处阶段：
受众常见的问题、误区或顾虑：
长期内容方向或固定栏目：
希望带来的价值及账号目标：
可公开的专业能力、经历、资源或案例：
不能出现的表达、承诺或敏感内容：
资质边界、地区限制或免责声明：

【表达方式】
语气、句长、信息密度和节奏：
喜欢的开头、内容结构和结尾：
本人常用的口头表达或句式：
不喜欢的AI腔或营销话术：
可以接受和不能接受的行动引导：

【样本与案例】
本人满意的文案、逐字稿或视频链接：
最满意的3条内容及原因：
不满意的版本和修改原因：
可参考但不能复制的账号或内容：
可以公开的真实经历或案例：
绝对不能虚构或使用的内容：
```

## 填写提示

- 受众阶段：写他们是谁、目前处于什么状态、希望解决什么问题。
- 内容栏目：列出以后经常发布的3–5类内容。
- 表达方式：说明喜欢的节奏、结构和口头表达，不需要使用专业术语。
- 行动引导：说明能否引导关注、私信、咨询或购买，以及哪些承诺不能出现。
- 样本与案例：粘贴链接后简单说明喜欢或不喜欢的原因；没有可写“暂无”。
